# services/device

Lecture du lecteur Accu-Chek Guide via `/usr/local/bin/accuchek`.

- `fetch(raw_dir)` : vérifie la présence du lecteur (sysfs, vendor `173a`), lance `/usr/local/bin/accuchek --set-time` sans root (accès USB donné par la règle udev `packaging/udev/70-glucofi-accuchek.rules`), ou `GLUCOFI_ACCUCHEK_CMD`, parse le JSON, garde une copie brute. Aucun fichier de configuration : la liste des lecteurs acceptés est intégrée à accuchek. Bloquant : à appeler hors du thread GTK.
- `parse_output(text)` / `parse_file(path)` : lit la sortie d'accuchek au format 2 (objet avec `meter`, `clock`, `glucose`, `meal`, `readings`) et l'ancien tableau de mesures (imports de fichiers anciens, sans lecteur ni horloge). Un en-tête invalide est fatal (`InvalidOutput`) ; les mesures invalides sont écartées et listées, pas fatales. Chaque `Reading` porte son marqueur repas (`Reading.meal`, `contracts.Meal`), sans effet sur l'égalité : une mesure relue avec un marqueur n'est pas un doublon. `ParseResult` / `FetchResult` exposent l'identité du lecteur (`MeterInfo`, nom du modèle d'après la table de Tidepool), l'horloge (`MeterClock` : écart lecteur - PC, action d'accuchek), les compteurs annoncés / reçus (`SegmentCount`), les marqueurs orphelins et `warnings` (textes à afficher : lecture incomplète, marqueurs orphelins, horloge à plus de 5 min non corrigée, mise à l'heure refusée). Les lectures hors échelle du lecteur sont gardées (`"range":"high"` = HI codé 601 mg/dL, `"range":"low"` = LO codé 9 mg/dL, voir `Reading.off_scale`) ; une mesure normale avec un `status` non nul est écartée avec son motif (`statut 0x....`), journalisé à l'import.
- Erreurs, avec un message affichable qui reprend la raison donnée par accuchek : code 2 `DeviceNotConnected`, code 3 `DeviceAccessDenied`, code 4 `DeviceReadFailed`, code 5 `DeviceProtocolError` (sous-classe de `DeviceReadFailed`), JSON illisible `InvalidOutput`. Codes : `contracts.AccuchekExit`, alignés sur `ExitCode` de `accuchek-src/session.h` (vérifié par `ExitCodeContractTest`). Un lecteur vide donne zéro mesure, sans erreur.
- `--set-time` : accuchek remet le lecteur à l'heure du PC si l'écart dépasse 60 s, seulement si l'horloge du PC est synchronisée (`adjtimex`) et si le lecteur se déclare réglable. Une commande explicite (`command=` ou `GLUCOFI_ACCUCHEK_CMD`) est lancée telle quelle, sans `--set-time` ajouté.
- `GLUCOFI_ACCUCHEK_CMD` remplace la commande (tests, autre binaire). Ne jamais définir `ACCUCHEK_DBG` : les logs d'accuchek partent alors sur stdout.
